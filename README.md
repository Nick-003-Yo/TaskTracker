# TaskTracker

## Описание

TaskTracker - небольшое консольное приложение для учета задач,
написанное на C#. При запуске программа выводит свою версию
и список задач с номером, названием и признаком выполнения.
Проект учебный: на нем отрабатывались аудит репозитория,
наведение порядка в структуре и обновление документации
с помощью Git.

## Используемые технологии

- C#
- .NET 8
- Git

## Требования

Для разработки и запуска нужен .NET 8 SDK.

Проверить установленную версию:

```
dotnet --version
```

## Запуск

1. Установить .NET 8 SDK.
2. Открыть терминал в корневой папке проекта.
3. Перейти в папку с проектом:

```
cd src/TaskTracker
```

4. Восстановить зависимости:

```
dotnet restore
```

5. Запустить программу:

```
dotnet run
```

Файла config/appsettings.Development.json в репозитории нет.
Если он нужен, надо скопировать config/appsettings.example.json
и вписать свои значения.

## Основные возможности

- вывод версии программы (1.3);
- создание задач (в текущей версии две задачи добавляются
  в коде программы при запуске);
- вывод списка задач в формате «номер: название | Выполнено: значение».
