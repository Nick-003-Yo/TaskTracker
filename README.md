# TaskTracker

## Описание

TaskTracker - консольное приложение для учета задач, написанное на C#.
Версия 2.1.1. Задачи можно создавать, изменять, удалять, искать и
фильтровать. Данные сохраняются в JSON-файл и загружаются при
следующем запуске. Есть отчёты по задачам и экспорт в CSV.

## Используемые технологии

- C#
- .NET 8
- JSON (System.Text.Json)
- Git

## Требования

Для разработки и запуска нужен .NET 8 SDK.

Проверить установленную версию: dotnet --version

## Запуск

1. Установить .NET 8 SDK.
2. Открыть терминал в корневой папке проекта.
3. Перейти в папку с проектом: cd src/TaskTracker
4. Запустить программу: dotnet run

Файл data/tasks.json создаётся автоматически при первом сохранении
и в репозиторий не попадает. CSV-отчёт сохраняется в папку reports.

## Основные возможности

- просмотр, создание, изменение и удаление задач;
- статусы (New, InProgress, Completed) и приоритеты (Low, Medium, High);
- исполнители и сроки;
- поиск по названию;
- фильтрация по статусу и приоритету;
- сохранение в JSON и загрузка после перезапуска;
- отчёт по задачам и список просроченных задач;
- экспорт в CSV.
