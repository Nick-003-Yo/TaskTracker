# Установка и запуск

1. Установить .NET 8 SDK.
2. Скачать проект:

```
git clone адрес_репозитория
```

3. Перейти на ветку с актуальной структурой и документацией:

```
git switch repository-improvement
```

4. Перейти в папку проекта:

```
cd src/TaskTracker
```

5. Запустить:

```
dotnet run
```
