# Требования к будущей веб-версии TaskTracker

## 1. Поддерживаемая среда

- WEB-01. Веб-интерфейс должен корректно работать в Mozilla Firefox и в современных Chromium-браузерах (Microsoft Edge, Google Chrome).
- WEB-02. Основные функции не должны зависеть от особенностей одного браузера. Перед выпуском интерфейс проверяется минимум в двух браузерах.

## 2. Работа с вкладками

- WEB-03. Пользователь может открыть приложение в нескольких вкладках. Изменения в одной вкладке не должны ломать данные в другой.
- WEB-04. Несохранённые данные формы не должны теряться при случайном закрытии вкладки: нужно предупреждение или черновик.

## 3. Всплывающие окна

- WEB-05. Критические функции (отчёт, экспорт, подтверждение действий) не должны работать только через автоматически открываемые окна, потому что браузер может их заблокировать.

## 4. Cookies

- WEB-06. Cookies используются только там, где они действительно нужны (сессия и настройки).
- WEB-07. Потеря или удаление сессии должна обрабатываться: пользователь видит понятное сообщение и возвращается на страницу входа, а введённые данные не пропадают молча.
- WEB-08. Основные функции не должны зависеть от сторонних cookies.

## 5. Авторизация

- WEB-09. Форма входа должна быть простой и использовать стандартные поля логина и пароля (с атрибутами autocomplete), чтобы с ней работали менеджеры паролей браузеров.

## 6. Разрешения браузера

- WEB-10. Приложение не должно запрашивать камеру, микрофон и геолокацию, если они не нужны для работы.
- WEB-11. Разрешение на уведомления запрашивается только после действия пользователя, а не сразу при открытии страницы.
- WEB-12. Отказ от уведомлений или другого необязательного разрешения не должен блокировать основную работу приложения. Важные сообщения дублируются внутри интерфейса.
