# Руководство пользователя (версия 2.1.1)

## 1. Назначение программы

TaskTracker - консольная программа для учета задач.
Она работает в терминале, мышь и окна не нужны.

## 2. Запуск

Нужен установленный .NET 8 SDK. Из корня проекта:

    cd src/TaskTracker
    dotnet run

## 3. Меню программы

1. Показать задачи
2. Создать задачу
3. Изменить задачу
4. Удалить задачу
5. Поиск
6. Фильтр по статусу
7. Фильтр по приоритету
8. Отчёты и экспорт
0. Выход

## 4. Порядок работы

1. Выбрать пункт меню, введя его номер и нажав Enter.
2. При создании ввести название, описание, исполнителя,
   приоритет и срок (срок в формате дд.мм.гггг, Enter - без срока).
3. При изменении задачи нажать Enter, чтобы оставить значение без изменений.
4. Для отчётов выбрать пункт 8: сводка, просроченные задачи,
   экспорт в CSV (файл reports/tasks.csv).
5. Пункт 0 сохраняет данные и закрывает программу.

## 5. Хранение данных

Задачи сохраняются в файл data/tasks.json и загружаются при запуске.

## 6. Ограничения

- графического интерфейса нет;
- для запуска нужен .NET 8 SDK.
