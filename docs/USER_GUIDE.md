# Руководство пользователя (версия 1.3)

## 1. Назначение программы

TaskTracker - консольная программа для учета задач.
Она работает в терминале, мышь и окна не нужны.

## 2. Запуск

Нужен установленный .NET 8 SDK. Из корня проекта:

```
cd src/TaskTracker
dotnet run
```

## 3. Основные возможности

- вывод версии программы;
- создание задач (в текущей версии две демонстрационные
  задачи задаются в коде программы);
- вывод списка задач в формате «номер: название | Выполнено: True/False».

## 4. Порядок работы

1. Открыть терминал в корневой папке проекта.
2. Перейти в папку src/TaskTracker и выполнить dotnet run.
3. Программа выведет версию и список задач.
4. После вывода списка программа завершает работу сама.

## 5. Ограничения

- графического интерфейса и интерактивного меню нет;
- ввод с клавиатуры не предусмотрен, задачи задаются в коде программы;
- для запуска нужен .NET 8 SDK.
