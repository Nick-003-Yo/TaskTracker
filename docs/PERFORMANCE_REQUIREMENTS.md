# Требования к производительности будущей веб-версии TaskTracker

## 1. Загрузка данных

- PERF-01. Приложение не должно загружать данные, которые пользователь в данный момент не использует. При открытии раздела загружается только то, что нужно для первого экрана.

## 2. Большие списки

- PERF-02. Список задач загружается постранично (например, по 50 записей), а не целиком. Следующая страница загружается по запросу пользователя.
- PERF-03. Поиск и фильтрация выполняются на сервере, а не в браузере по всем записям.

## 3. Клиентский JavaScript

- PERF-04. Клиентская логика должна быть лёгкой. Длительные вычисления нельзя выполнять в основном потоке, чтобы не замораживать интерфейс.

## 4. Медиа и вложения

- PERF-05. Вложения, изображения, комментарии и история изменений загружаются только при открытии карточки задачи или по действию пользователя (lazy loading).

## 5. Автообновление

- PERF-06. Приложение не должно проверять сервер каждую секунду. Обновление выполняется реже (например, раз в 30–60 секунд) или по сигналу от сервера.

## 6. Работа на слабых компьютерах

- PERF-07. Интерфейс должен оставаться работоспособным на компьютерах с небольшим объёмом оперативной памяти и при открытых десятках вкладок.

## 7. Проверка производительности

- PERF-08. Перед выпуском веб-версии производительность проверяется измерениями (время загрузки, использование RAM и CPU), а результаты записываются в репозиторий.
